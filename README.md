# Spring Boot Task 1

## Description
Simple Spring Boot MVC application with Thymeleaf.

## Technologies
- Java
- Spring Boot
- Thymeleaf
- Maven

## Features
- Home endpoint
- Greeting page
- Image display

## Run Project
1. Open in IntelliJ
2. Run DemoApplication.java
3. Open:
   - http://localhost:8080
   - http://localhost:8080/greeting
